# GrowthSathi brand assets

`growthsathi-logo.png` is copied directly from the approved `docs/design-references/Growthsathi_main_logo.png` source asset. Do not crop branding from the AI-generated page references and do not recreate screenshot-only artwork.

Phase 8 delivery uses `growthsathi-logo.webp`, a lossless encoding of the same 1254 x 1254
image. All decoded RGBA pixels were compared and are identical; both files were visually
inspected. PNG: 1,660,497 bytes; WebP: 1,247,538 bytes (24.87% smaller). The original PNG
and official design-reference source are retained unchanged. No resampling or redesign.
